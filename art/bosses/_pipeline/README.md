# ボスのドット絵の作り方(イラストから)

2026-11-10 に決めた作り方。新しいボスは全部これで作る。

## 1. 元のイラストを作る(Canva の画像生成)
頼み方のひな形(テーマ・髪・服・持ち物だけ入れ替える):

> オリジナルキャラクターの全身イラスト。弾幕シューティングゲームのボスの少女「〇〇」。レトロなシューティングゲームのドット絵の立ち絵のような体型で、頭が大きめ、全身の高さは頭3つ半ぶん(3.5頭身)。手足は短めだけど、赤ちゃんっぽくはしない。表情はかわいすぎない不敵な笑みで、少しつり目。(髪・服・持ち物)。宙に浮いて片足を曲げたポーズ、ほぼ正面。濃い輪郭線、1段のベタ影、グラデーションなし、色数少なめ。全身。背景は真っ白の無地。

- 既存の作品のキャラに似せない(見た目の組み合わせが有名キャラと同じにならないようにする)
- 6頭身くらいで返ってきたら、もう一度頼む

## 2. ドット化
`art/bosses/<ID>/source/` に `<ID>_source.png`(元絵)と `<ID>_face.json`(目と口の位置)を置いて:

    python3 art/bosses/_pipeline/make_still.py art/bosses/<ID>

→ `source/<ID>_still.png`(高さ66ドット、透明背景)

決まりごと(参考にしたドット絵のステッカーを測って決めた):
- 黒い枠は使わない。輪郭はとなりの塗りの色を少し濃くした色(白のふちはうすいピンク、肌のふちは明るい赤茶)
- 黒は黒い物(帯・下駄など)の面だけ
- 素材ごとに色は3段(肌と白は2段)。1ドットだけ違う色の点は、まわりの色にそろえる
- 灰色は使わない
- 目は赤(またはそのキャラの瞳の色)の縦長 2×3、上にまぶたの影1列。顔の陰影は残す

キャラごとの手直し(持ち物の形など)は `source/polish_<ID>.py` に書く。
高さを変えたいときは `source/<ID>_settings.json` に `{"height": 80}` のように書く(顔が小さくなる絵は 80〜100)。

### 2-b. 色の表を使うドット化(黒が多い・白が多い・細い金の線がある絵)
ふつうのドット化(色を平均してから減らす)は、黒の多い絵(堕天使・死神)だと細い金の線が茶色に濁り、白の多い絵(雪の女王)だと肌が白に溶ける。
そういう絵は、`source/<ID>_settings.json` に `"palette"` を書くと `pixel_pal.py` に切り替わる(pixel4・material・degrey の代わり):

- 素材ごとに `tones`(ふつう・暗い・明るい…の色)と `anchors`(元絵の色 → 何段目か)と `weight`(細くても残したい物ほど大きく。金 2.4、光る球 1.6、黒い線 0.3〜0.75)
- `edge`: ふちに使う段。黒い物は 2(明るい段)にして、暗い背景に溶けないようにする
- `_fringe`: 背景とのにじみが化けやすい素材(髪・肌など)。外側の1ドットをとなりの素材に直す
- `hole_min`: 輪っかの内側など、閉じた白をこのドット数以上なら透明にする(初期値 60。白い服のキャラは 0)
- 見本: `fallen_angel/` `ice/` `reaper/` の `source/<ID>_settings.json`

元絵の色は、元絵の色を数えて(16刻みで多い順)決める。

## 2.5 部位の地図(どのドットが何か)
元絵(大きいほう)の上で、部位ごとの形を `source/<ID>_parts.json` に多角形で書く。種類は5つ:

| 種類 | 例 | 動かし方 | 動いたあとの空いた所 |
|---|---|---|---|
| body | 体・顔・手足 | 動かさない | — |
| flow | ひれ・すそ・マント | 下ほど大きく左右にゆれる | 後ろの体の色で埋める |
| ribbon | リボン・髪飾り | 少し上下左右 | 後ろの髪の色で埋める |
| held | 手に持った物 | 動かさない(手から離れて見えるので) | — |
| floating | 手の上に浮いている物など | 上下に浮く | 透明のまま(影を残さない) |

書いていない所は全部 body。`make_still.py` が `source/<ID>_partmap.png`(1ドットごとの部位の番号)と、確認用の色分け `source/<ID>_partmap_view.png` を作る。

## 3. アニメ・覚醒
`art/bosses/<ID>/make_<ID>.py` で、1枚の絵から全状態(待機・構え・技中・硬直、覚醒の4つ)を作る。共通の処理は `../tools/bosskit.py`。
待機は `from_still_parts` と `idle_parts_map` で、部位の名前を指定して動かす。体・手・持ち物は動かさない。

部位の地図で気をつけること(作り直しのときに出た失敗):
- 部位の形に手を入れない(手まで揺れて、ちぎれて見える)。手の場所は形を切り欠いて避ける
- 脚・足先は動かさない(すそが揺れる形は、脚の左右で分ける)
- floating は空いた所が透明になるので、体や翼の上に重なる物(手の上の球など)は ribbon にする
- floating の形は物にぴったり(大鎌の刃などを巻き込むと穴が開く)
- floating は「まわりに何もない所に浮いている物」だけ(九尾の狐火のように尻尾の先に重なる物は ribbon。floating だと跡が透明の線になる)
- flow は1行ずつずらすので、行の端や行と行のあいだに1ドットの透明な切れ込みができる。`rig_frame` の最後で、上下か左右を色にはさまれた透明なドットを埋めている(消さないこと)

### 仕上げの確認(プッシュの前に毎回)
- 待機8コマを暗い背景に並べて、拡大して見る(GIF も作る)
- 透明な切れ込みを数える: 上下か左右を色にはさまれた透明なドット。元の絵(`from_still_parts` の base)より増えていたら、どこかの部位の種類か形がおかしい
- 手・持ち物・脚が動いていないか、浮いた物の下に影が残っていないか

## 4. 仕上げ
技の発射位置(`patterns/engine.js` の座標)を新しい絵に合わせる。元絵の座標 → 1コマの座標は `tools/srcpos.py` の `to_frame` で出す。
`patterns/build.py`(試射場)と `tools/build_viewer.py`(ボス図鑑)を作り直してプッシュ。

## 最強のドラゴンだけ、作り方が違う(2026-11-12)
Koshin の指示(もっとぬるぬる・もっとかっこよく・飛び回る・動きの種類をめちゃくちゃ多く・覚醒3段階・技10個)で、上の作り方では足りないので、専用の作り方にした。場所は `dragon/`。
- **元絵**: Canva で生成して、高解像度(1456×1088)で取り出したもの(`source/dragon_art.png`)。取り出し方: 生成した絵を「レイヤーに分ける」でデザインに変換 → PNG で書き出す
- **骨組み(`rig.py` + `source/dragon_rig.json`)**: 元絵を部位(頭・あご・首・腕・脚・体・翼・尻尾)に分け、骨で動かしてから1コマごとにドット化する。小数の位置で動かせるので、整数ドットでずらすより滑らか。色は決まった表の色だけ
- **動き(`moves.py`)**: 待機48コマ + 技ごとの動き10種類(構え12・技中16・硬直6)。1コマ 0.04 秒、1コマ 240×200
- **横向きに飛ぶ姿(`side.py` + `source/dragon_side.json`)**: 同じ竜を真横から描いた絵(`source/dragon_side_art.png`)を、同じやり方で動かす。左向き・右向きの2つ(各24コマ)
- **絵の中の光(`make_dragon.py` の effects)**: 口の炎・爪の軌跡・衝撃波など。試射場の演出(炎の柱・爆発・火花・画面のゆれ)は `patterns/template.html` と `engine.js`
- **姿は4つ**(通常 / 覚醒1 蒼炎 / 覚醒2 紫電 / 覚醒3 白金): 絵は「色の番号」で1組だけ持ち(`sheets/`)、姿ごとの色の表(`forms.json`)で塗り分ける
- **書き出し**: `python3 dragon/make_dragon.py`。試射場(`patterns/build.py`)とボス図鑑(`tools/build_viewer.py`)は `sheets/` があるボスを特別扱いする
- **技**: 弾より、範囲攻撃・本体の体当たり・風・引き寄せ・バインド・即死・自機の弾の吸収が中心。試射場のエンジン(`patterns/engine.js`)に仕組みを足した。ゲーム本体にはまだ無い仕組みなので、入れるときは `docs/BOSS_EXCLUSIVE_PATTERNS.md` の注意を読むこと
- 新しいボスをこの方式で作るなら、`dragon/` をまねる(部位の範囲と関節を元絵の座標で書く。座標は必ず目盛りの数字で読むこと)
