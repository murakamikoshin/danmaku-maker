# ボスのドット絵の作り方(イラストから)

2026-11-10 に決めた作り方。新しいボスは全部これで作る。

## 1. 元のイラストを作る(Canva の画像生成)
頼み方のひな形(テーマ・髪・服・持ち物だけ入れ替える):

> オリジナルキャラクターの全身イラスト。弾幕シューティングゲームのボスの少女「〇〇」。レトロなシューティングゲームのドット絵の立ち絵のような体型で、頭が大きめ、全身の高さは頭3つ半ぶん(3.5頭身)。手足は短めだけど、赤ちゃんっぽくはしない。表情はかわいすぎない不敵な笑みで、少しつり目。(髪・服・持ち物)。宙に浮いて片足を曲げたポーズ、ほぼ正面。濃い輪郭線、1段のベタ影、グラデーションなし、色数少なめ。全身。背景は真っ白の無地。

- 既存の作品のキャラに似せない(見た目の組み合わせが有名キャラと同じにならないようにする)
- 6頭身くらいで返ってきたら、もう一度頼む

## 2. ドット化
`art/bosses/<ID>/source/` に `<ID>_source.png`(元絵)と `<ID>_face.json`(目と口の位置)を置いて:

    python3 art/bosses/_pipeline/make_still.py art/bosses/<ID>

→ `source/<ID>_still.png`(高さ66ドット、透明背景)

決まりごと(参考にしたドット絵のステッカーを測って決めた):
- 黒い枠は使わない。輪郭はとなりの塗りの色を少し濃くした色(白のふちはうすいピンク、肌のふちは明るい赤茶)
- 黒は黒い物(帯・下駄など)の面だけ
- 素材ごとに色は3段(肌と白は2段)。1ドットだけ違う色の点は、まわりの色にそろえる
- 灰色は使わない
- 目は赤(またはそのキャラの瞳の色)の縦長 2×3、上にまぶたの影1列。顔の陰影は残す

キャラごとの手直し(持ち物の形など)は `source/polish_<ID>.py` に書く。

## 3. アニメ・覚醒
`art/bosses/<ID>/make_<ID>.py` で、1枚の絵から全状態(待機・構え・技中・硬直、覚醒の4つ)を作る。共通の処理は `../tools/bosskit.py`。
