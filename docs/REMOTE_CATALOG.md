# サーバーから配る商品(ショップの「新着」)

アプリの更新なしで、ショップの「見た目」タブの先頭に、新しいドット絵の自機を出せる仕組み(2026-11-10)。

## 何を配れるか
- 配れるのは、**絵と数値のデータだけ**(32×32 の透過 PNG、3〜8コマ、名前、無料か商品 ID)。動きを変えるプログラムは配らない(Apple の規約)。
- いまの種類は `ship`(ドット絵の自機)だけ。ボスは、動きや当たり判定がアプリの計算の中にあるので、配れない(アプリの更新が要る)。
- 有料にするときは、先に App Store Connect と RevenueCat に商品(`com.koshin.danmakumaker.…`)を作る。新しい課金商品の審査は要るが、アプリの更新は要らない。無料の自機は、審査なしで出せる。

## 出し方
1. `tools/catalog/shop.src.json` に項目を足す(形は `tools/publish_catalog.mjs` の先頭に書いてある)。絵は `art/rewards/` などに置く。
2. `GOOGLE_APPLICATION_CREDENTIALS=<管理者の鍵> node tools/publish_catalog.mjs` で、Firestore の `catalog/shop` に書く(Koshin が鍵を作る。リポジトリには置かない)。
3. アプリは、起動して(サインインできたあと)この文書を読み、端末にも残す。読めなくても、残してあるものを使うので、動かなくなることはない。

## 安全のために
- 書けるのは管理者だけ(ルール: ログイン済みなら読めて、誰も書けない)。
- アプリ側でも、ID の形(`x_…`)・絵の大きさ(32×32)・コマ数・商品 ID の頭(`com.koshin.danmakumaker.`)を確かめて、使えないものは飛ばす。
- 消した自機を使っていた人は、標準の自機に戻る。
- 文書の大きさは 1MB まで(絵を base64 で入れている)。
