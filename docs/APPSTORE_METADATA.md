## 審査メモ（App Review Information）
```
【ログイン】
遊ぶだけならログイン不要です。ステージの投稿・いいね・通報には Sign in with Apple が必要です（審査用のデモアカウントは不要で、審査用の Apple ID でそのままサインインできます）。

【投稿の確認方法】
1. ホーム右上の「＋」→エディタで発射台を1つ以上置き、「テストプレイ」で自分でクリアする（耐久は最短10秒）。
2. 「投稿する」→利用規約に同意→Apple でサインイン→投稿。
投稿には、作者本人がテストプレイでクリアすることが必須です。

【UGC 対策】
・ステージ詳細画面から「通報する」「作者をブロック」ができます（ブロックした作者のステージは一覧に出ません）。
・ステージ名・作者名は NG ワードで検査し、規約への同意が必要です。複数の通報で自動的に非公開になります。
・サポート連絡先: アプリの設定画面とサポートページに掲載。
・アカウント削除: 設定 → アカウントを削除（Apple でサインインしたユーザーのみ表示）。

【広告・課金】
広告は、被弾後の「広告を見て復活」（リワード広告）のみです。「広告削除」は買い切りで、購入の復元ボタンは設定画面と購入画面にあります。
```
