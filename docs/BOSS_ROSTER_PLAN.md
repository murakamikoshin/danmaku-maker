# ボス6体の移植計画

素材: `~/Downloads/danmaku-bosses-handoff.zip`(ボス7体のドット絵・待機アニメ・攻撃の仕様。`HANDOFF.md` と `reference/engine.js`)。
堕天使は実装済み(`BossCharacter.fallenAngel = 5`、技5つ、覚醒、買い切り商品、無料チケット)。残りの6体を、同じ作りで入れる計画です。
2026-11-09 作成。コードはまだ入れていません(課金・サーバー検証・秘密の扱いが絡むので、起きているときに進めます)。

## 決めること(資料の決定事項)

- ボスは「エディタのパーツ」。1ステージに1体まで。見た目+得意技+覚醒。遊ぶ側は無料、作る側は買い切りの非消耗型(購入の復元あり)。
- 無料チケット: 最初のステージを公開したとき、好きなボス1体を選べる(堕天使で実装済み)。
- 買う前に試せる(未所持でも、エディタでテストプレイまで)。購入が必要になるのは公開するとき(実装済みの仕組みを使う)。
- **ぷにまるだけ、覚醒を秘密にする**: ショップ・選択画面では「ザコ」にしか見せない。未所持のテストプレイでは覚醒させない。ステージで遭遇したときだけ覚醒する。

## 1体ごとの作業(堕天使と同じ手順)

各ボスで、Swift(`DanmakuCore`)・サーバー(`fullsim.ts`)・アプリを、同じ計算でそろえます。堕天使の段階1〜4のコミット(`b8dff96` など)が見本です。

| 手順 | 中身 |
|---|---|
| 1. 素材 | `sprites/sheets/<名前>_idle_sheet.png` を `DanmakuApp/Resources/Bosses/` に入れる(横8コマ・112×112。ぷにまる覚醒は136×112)。`BossSprites` に登録。最近傍補間 |
| 2. 列挙 | `BossCharacter` に追加(rawValue は 6〜11)。`productKey`(商品 ID)、`hitRadius`、発射位置、ボスの動き(待機の揺れ) |
| 3. 技 | `engine.js` の各ジェネレータ(`kitsune()` `witch()` `mech()` `ice()` `reaper()` `puniWeak()` `puniTrue()`)を、`Simulation` の弾の「印(script)」と技のパターン(`Pattern` の新しいケース)に移す。60fps の px/フレームを、1/120 秒のステップに直す |
| 4. サーバー | `fullsim.ts` に同じ計算を移し、`validate.ts` の「そのボスにだけ置ける技」の検査を足す |
| 5. 照合 | `FixtureExportTests` の末尾に、そのボスのステージを足して正解データを書き出し、`fullsim.test.ts` で Swift とサーバーの一致を確認する(堕天使と同じ。既存の並びは変えない) |
| 6. 画面 | エディタのボス選択・ショップのボスタブ・クリア画面の「このボスを使う」に出す。10言語の名前・説明 |
| 7. 商品 | App Store Connect と RevenueCat に買い切りを登録(`tools/asc_create_iaps.mjs` `tools/rc_create_products.mjs` が見本。**あなたの作業**) |
| 8. 公式ステージ | ボスごとに見本ステージを1つ(`tools/make_official_stages.py`) |

## おすすめの順番(難しさ・負荷の小さい順)

1. **雪の女王「六花・結晶の檻」**: 6方向の弾が30フレームごとに2つに分かれる(分裂弾の仕組みが既にある)。仕組みの追加が少ない。
2. **九尾の巫女「狐火・九つの灯」**: 尻尾の先に灯る弾が、順に自機へ飛ぶ。周回する御札が36フレーム後に直角に曲がる(「ジグザグ」の印が使える)。
3. **死神「刈取・三日月の大鎌」**: 弧に沿って置いた弾を、30フレーム後に一斉に落とす(「停止弾→落下」の印が使える)。魂弾はゆっくりの追尾弾。
4. **深海の魔女「深淵・提灯の誘い」**: 画面の暗転(提灯と自機のまわりだけ見える)。描画の新規作業が要る。計算は弾列の揺れだけ。
5. **機神「照準・コアアイ・ロックオン」**: 追う予告線→固定→極太ビーム(チャージビームの仕組みが使える。幅26)。旋回制限つきのホーミングミサイル。
6. **ぷにまる(ギャップボス)**: 一番最後。覚醒の秘密、グリッチ演出、目22個、触手12本の螺旋、24方向の歯弾、2色の回転レーザー、**弾の瞬間移動**(75 フレームごと)。弾が多いので、負荷の確認を先にする。

## 注意(資料の指摘)

- 難易度は未調整。実機でテストプレイして、数値を決める。
- 堕天使の「失楽園」の抜け道ルール(前の輪の抜け道 ±90°以内)は、すでに実装済み。ぷにまるの瞬間移動は「現仕様のまま入れる」(Koshin の判断)。救済(移動先の予告)は、実機で見てから。
- 弾数が多い技(最大約400発)は、`DanmakuConfig.maxBullets` と負荷を確認する。
- 「覚醒」は汎用の仕組みとして、**どのボスにも付けられる**(実装済み。`awaken`)。覚醒のシート差し替えは、堕天使と同じ流れ。

## 見積もり

堕天使1体の段階1〜4が、数日分の作業でした。6体なら、1体あたり同じ程度。順番に出していき、1体ごとに TestFlight で確認するのが安全です。
