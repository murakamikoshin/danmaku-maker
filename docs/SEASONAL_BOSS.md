# 期間限定のボス(売り場に出す期間を切り替える)

1.5.0 で入れた仕組み。最初の1体はクリスマス限定のサンタ娘(`BossCharacter.santa`、番号 14、商品 `com.koshin.danmakumaker.boss.santa`、¥400)。

## 決まりごと(Koshin の決定、2026-11-24)
- 買い切りのボス。売るのは期間中だけ(2026年は、1.5.0 の公開日 〜 12/26 17:00 日本時間)。
- **永久買い切りパックの人は、期間に関係なくいつでも使える**(期間のあとに永久パックを買った人も)。「これから追加される課金コンテンツも全部」と約束して売っているため。
- 期間中に買った人は、期間が終わってもずっと使えて、購入の復元もできる。
- 無料チケットではもらえない。来年も復刻で売る(文言は「期間限定販売」。「今年だけ」とは書かない)。
- 限定ボスのステージを**遊ぶのは誰でもできる**(記録もランキングに載る)。持っている必要があるのは、**公開するとき**だけ。

## 2つの値を分けてある(ここを混ぜない)
| 値 | 意味 | 期間外 |
|---|---|---|
| `BossCharacter.purchasable` | 商品として存在する = 永久買い切りパックに含む | **true のまま** |
| `BossCharacter.onShelf(_:)` / アプリの `SeasonConfig` | いまショップの売り場に出す | false |

- 所持の判定(`Ownership.has`、サーバーの `ownsBossByPurchase` / `missingBosses`)は、**販売中かどうかを見ない**。買った記録(単品か永久パック)だけで決める。
- `purchasable` を期間で false にしてはいけない(永久パックの人が使えなくなり、買った人の復元もできなくなる)。テスト `ShopTests.testSeasonalBoss…` と `ownership.test.ts`「期間限定のボス」が守っている。

## 販売中かどうかの決め方
- Remote Config の `xmas_boss_on_sale`(`firebase/remoteconfig.template.json`)。既定は false、条件 `xmas_sale_2026`(日時)の間だけ true。
- **端末の時計は使わない**。条件は、アプリが設定を取りに来た時刻でサーバーが決める。
- アプリは起動時などに取り直す(最短 1 時間おき)。だから、終わりの時刻から売り場が消えるまで、人によって 1 時間以上ずれる。
- 取れなかったときは前回の値(初回は false = 売り場に出さない)。
- TestFlight・審査用のビルドでは、設定に関わらず売り場に出す(Apple が商品を審査できるように)。

## 期間外の見え方
- ショップ: カードを出さない。持っている人(単品・永久パック)には「購入済み」として残る。
- エディタ: ボスの選択肢には残る。持っていない人は、置いてテストプレイまで(公開はできない)。案内は「永久買い切りパックなら使える」で、ボタンは永久パックのカードへ。
- 公開の画面: 持っていない人には「いまは単品では販売していません。永久買い切りパックなら使えます」。
- ボス図鑑(web の boss_zukan.html)には、いつも載せる。

## 始めるとき(毎年)
1. App Store Connect(ASC): 商品 `boss.santa` が「承認済み」で、配信地域が入っていること(去年「販売から削除」にしたなら、配信地域を入れ直す。審査は要らない)。
2. RevenueCat: 商品が登録されていること(消していなければ何もしない)。
3. Remote Config: 条件の名前と日時をその年のものに直す(例 `xmas_sale_2027`)。**デプロイの前に、本番のいまの値(`update_latest_version` など)とひな形を見比べる**(ひな形で上書きされる)。Koshin の確認をもらってから `firebase deploy --only remoteconfig`。
4. アプリの更新は要らない(1.5.0 以降なら、設定だけで売り場に出る)。

## 終わるとき
1. 何もしなくても、条件の終わりの時刻で `xmas_boss_on_sale` が false になり、売り場から消える。
2. **翌日以降**に、ASC で販売を止める(売り場の表示が古いままの人が残っている間に止めると、値段が出ないボタンが見えるだけで害はないが、念のため 1 日あける)。
   - ASC → 弾幕メーカー → アプリ内課金 → `boss.santa` → 「配信状況(Availability)」→ 「販売から削除(Remove from sale)」→ 保存。状態が「デベロッパにより販売から削除」になる。
   - **商品は削除しない**(削除すると元に戻せず、同じ商品 ID も二度と使えない)。RevenueCat の商品も消さない。
3. 止めたあとに確かめる(サンドボックスのテスト用アカウントで):
   - 期間中に買ったアカウントで「購入を復元」→ サンタ娘が使えるまま。
   - 永久買い切りパックのアカウント → 使えるまま。
   - 何も持っていないアカウント → ショップにカードが出ない。エディタで選ぶと案内が出て、公開は断られる。
   - 復元できなかったら、すぐ ASC で配信地域を入れ直す(売り場はアプリ側で消えているので、ASC を販売中に戻しても買われることはない)。

### 販売から削除したあとの復元について(未確認の点)
Apple のいまの説明では、販売から削除しても、買った人は使い続けられ、取引は StoreKit から取れる。ただし古い説明には「復元できない」と書いたページも残っている。**本番で止める前に、サンドボックスで「買う → 販売から削除 → 復元」を一度試す**。
不安が残るなら、ASC では止めず、アプリの売り場から消すだけにする手もある(売り場に出ていなければ、買う入口はない)。

## 新しい期間限定のボスを足すとき
- `SaleSeason` に期間を足す(Remote Config のキーは `<名前>_boss_on_sale`)、`BossCharacter.season` で結びつける。
- サーバー: `ownership.ts` の `BOSS_BY_LOOK`・`SEASONAL_BOSSES`・`PAID_ONLY_BOSSES`(チケットでもらえないなら)。`NOT_IN_LIFETIME` には入れない。
- 永久買い切りパックの説明(`lifetime.item.5`)は季節を書いていないので、直さなくてよい。

## 同じ期間で売る、ボス以外の商品(1.5.0、2026-11-25)
クリスマスの期間(`SaleSeason.xmas`、Remote Config の `xmas_boss_on_sale`)は、ボスのほかに次の商品も同じスイッチで売り場に出す。**始めるとき・終わるときの ASC の手順は、下の商品も全部いっしょにやる**。

| 商品 ID(`com.koshin.danmakumaker.` のあと) | 中身 | 目安の値段 | コード |
|---|---|---|---|
| `boss.santa` | ボス「クリスマス娘 ノエル」 | ¥400 | `Product.boss(.santa)` |
| `mooks.xmas` | 雑魚の見た目 4種(番号 5〜8: 雪だるま・プレゼント箱・ジンジャーマン・鈴) | ¥200 | `Product.mooks(.xmas)`、`MookPack.xmas` |
| `pack.xmas` | クリスマスパック(上の全部入り) | ¥600 | `Product.seasonPack(.xmas)` |

- 雑魚の見た目もボスと同じ考え方: **遊ぶのは誰でもできる**。公開するのに持っている必要がある(アプリは `Ownership.has(mookLook:)`、サーバーは `ownership.ts` の `missingMookPacks`。エラーは `mooks-not-owned`)。
- 永久買い切りパックの人は、期間に関係なく使える。クリスマスパックを買った人は、その期間のボスと雑魚の見た目を全部使える(サーバーは `pack.xmas` の購入を見る)。
- 雑魚の見た目は計算に関わらない。古い版(1.4.2 まで)は 5 以降を知らないので、標準の見た目で出る(遊べる。`needs` は付けない)。
- 自機・テーマを足すときは、パックの中身(`Ownership.hasAll(of:)` と、サーバーの判定)にも足すこと。
