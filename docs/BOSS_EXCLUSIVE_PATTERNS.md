# ボス専用の技(限定弾幕パターン)

堕天使と同じ仕組みで、**そのボスを選んでいるときだけステージに置ける技**を、ほかのボスに5つずつ。
弾の見た目も、ボスごとに専用のものを使う。動くプレビューは `art/bosses/patterns/`(`python3 build.py 出力.html` で作れる)。

## 決まりごと(堕天使と同じ)

- `Pattern` に case を足す(並びは変えず、必ず後ろに足す)。`Pattern.<ボス>` の一覧と `bossCharacter` に入れて、そのボスを選んでいるときだけ置けるようにする
- 覚醒すると、同じ技が強くなる(`awakened` を見る)。ぷにまるだけは、覚醒で技そのものが別物になる
- サーバー(`fullsim.ts`)にも同じ計算を入れ、`validate.ts` で「そのボスにだけ置ける技」を検査する。照合は `FixtureExportTests`
- 数値は見栄えで決めたもの。60fps の px/フレーム で書いているので、Swift では 1/120 秒のステップに直す(`v * 60` が px/秒)
- ぷにまるの覚醒の技名は、ショップ・選択画面・未所持のテストプレイでは出さない(秘密の方針)

## 九尾の巫女

発射位置(絵の中のドット): 尻尾の付け根 (56,51)。尻尾の先の狐火 k=0〜8(左下→上→右下): (24,71) (21,54) (26,36) (40,24) (72,21) (84,32) (91,42) (94,57) (89,73)。御札 (48,19)

### 1. 狐火「九つの灯」(看板技)

- case: `kitsuneLanterns`
- 弾: 狐火
- 動き: 九本の尻尾の先に、狐火が端から順に灯る。灯り終わると、同じ順番で一つずつ自機へ飛んでくる。
- 覚醒: 2周する(2周目は逆の端から)。1つの先から3wayで撃つ。速さ 3.2→3.8。
- 数値: c=9(灯の数) / v=3.2 / 灯る間隔 5フレーム、撃つ間隔 5フレーム

### 2. 御札「直角結界」

- case: `kitsuneBarrier`
- 弾: 御札
- 動き: 尻尾の付け根から御札が輪になって広がり、36フレームで直角に曲がる。曲がる向きは1枚ごとに左右交互で、格子の結界になる。
- 覚醒: 1回の枚数 12→18。72フレームでもう一度曲がって、ジグザグになる。
- 数値: c=12 / v=2.0(曲がったあと1.2倍) / 3回、40フレームごと、1回ごとに15°ずらす

### 3. 狐雨「天気雨」

- case: `kitsuneSunshower`
- 弾: 狐火、御札
- 動き: 空から狐火が雨のように降る(左右にゆらゆら)。30フレームごとに、自機狙いの御札3wayが混ざる。
- 覚醒: 降る量が2倍、速さ 2.2→2.8。
- 数値: 雨: 4フレームごとに1粒、v=2.2、150フレーム / 御札: 3way・v=2.6

### 4. 鳥居「千本鳥居」

- case: `kitsuneTorii`
- 弾: 御札
- 動き: 御札が横一列の壁になって、ゆっくり下りてくる。壁には1か所だけ通り道があり、1列ごとに左右へずれる。鳥居をくぐっていく感覚。
- 覚醒: 通り道 60→48px。壁が左右にゆらゆら揺れる。
- 数値: 8列、26フレームごと / 札の間隔 16px / v=1.4 / 通り道のずれ 30〜60px(画面の端から50px以内には出さない)

### 5. 九尾「玉藻の舞」

- case: `kitsuneDance`
- 弾: 狐火
- 動き: 九本の尻尾の先から、下向きの扇に狐火を撃ち続ける。扇は尻尾ごとに揺れて、舞うような模様になる。
- 覚醒: 1つの先から2本ずつ(揺れが逆向き)。速さ 2.2→2.6。
- 数値: 4フレームごと×120フレーム / 9本 / v=2.2 / 揺れ幅 ±0.5rad

## 最強のドラゴン

発射位置(絵の中のドット): 口 (83,46)、胸 (83,62)、爪 左 (44,72) / 右 (123,72)、翼の先 左 (7,43) / 右 (160,43)。※絵は 168×128。コマ数がほかの3倍(待機24・構え12・技中12・硬直6、1コマ 0.04 秒)

### 1. 竜王「劫火の咆哮」(看板技)

- case: `dragonBreath`
- 弾: 劫火、火の粉
- 動き: 口から炎の帯を吐き続ける。帯の向きは、ゆっくり自機を追いかける。追う速さより自機のほうが速いので、横へ走り続ければ抜けられる。炎はときどき火の粉を落とす。
- 覚醒: 蒼い炎になり、量が2倍、帯が太くなる。吐き始めに、口から自機狙いの極太ビーム(予告50フレーム)。
- 数値: 2フレームごと(覚醒は毎フレーム)×170フレーム / v=3.0〜4.2 / 帯の幅 ±0.18rad(覚醒 ±0.26) / 追う速さ 0.006rad/フレーム(覚醒 0.0075)

### 2. 翼撃「紅蓮の烈風」

- case: `dragonGale`
- 弾: 竜鱗
- 動き: 羽ばたきに合わせて、翼の先から竜鱗の扇を左右交互に撃つ。竜鱗は内側へ曲がりながら飛び、左右の扇が画面の真ん中で交差する。
- 覚醒: 左右同時に撃つ。1回 9→11枚、8回。
- 数値: 6回、24フレームごと / v=2.2 と 2.7 を交互 / 扇の間隔 0.13rad / 曲がる速さ 0.009rad/フレームを70フレームまで

### 3. 爪撃「金剛裂爪」

- case: `dragonClaw`
- 弾: 爪痕
- 動き: 爪の軌跡を薄い線で24フレーム予告してから、3本の爪痕が自機のいた場所へ斜めに走る。左右の手で交互に。
- 覚醒: 爪痕 3→5本。左右同時に振るので、X の形に交差する。
- 数値: 4回、40フレームごと(覚醒46) / 線の間隔 26px / v=5.2 / 1本につき爪9つ、2フレームごと

### 4. 隕星「メテオフォール」

- case: `dragonMeteor`
- 弾: 隕石、火の粉
- 動き: 空から隕石が、自機のいた所へ斜めに落ちてくる。通ったあとに火の粉が残って、ゆっくり降る。落ちる前に、画面の上できらっと光って予告する。
- 覚醒: 隕石 5→8個。下まで落ちると砕けて、炎の輪になる(1つは必ず自機の方を向く)。
- 数値: 36フレームごと(覚醒28) / 予告30フレーム / 隕石 v=3.0(覚醒3.4) / 火の粉 6フレームごと・v=0.5〜0.9・150フレームで消える

### 5. 逆鱗「竜王の怒り」

- 動き: 胸から竜鱗の渦が回りながら広がる。50フレームごとに、吠え声のように炎の輪が広がる(ゆっくり出て加速)。輪には自機の近くに抜け道が1つある。

- 数値: 渦: 5フレームごと×170フレーム、v=2.0、曲がる速さ 0.006rad/フレーム / 輪: v=1.0 から 3.2 まで加速、抜け道は弾3つぶん

## 避けられるかの注意

- 壁の技(九尾「千本鳥居」、死神「デッドライン」)は、通り道を1列ごとに最大80pxまでしかずらさない。画面の端から50px以内には出さない
- 機神のビームは固定から発射まで14フレーム。13px動けば避けられる
- 死神「三日月の大鎌」は、止まってから30フレーム待つので読める。覚醒は2重になるので、刃の列に隙間を2か所あける
- 死神「冥府の鎖」は、伸びる前に20フレーム予告線を出す
- ぷにまる覚醒「位相のずれ」は、移動先に30フレーム前から印を出し、自機から40px以内には出さない(前に話した救済をはじめから入れた)
- ドラゴン「劫火の咆哮」は、炎の帯が自機を追う速さ(0.006rad/フレーム。400px 先で 2.4px/フレーム)を自機より遅くしてある。覚醒のビームは予告50フレーム
- ドラゴン「金剛裂爪」は、走る前に24フレーム予告線を出す。「メテオフォール」は落ちる30フレーム前に上で光る
- 弾数が多い技(魔女「渦潮」、九尾「天気雨」覚醒、ぷにまる「螺旋の腕」、ドラゴン「劫火の咆哮」覚醒)は `DanmakuConfig.maxBullets` と負荷を確認する
