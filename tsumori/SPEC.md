# ガマンの塔（仮称） 仕様書（MVP）

買うのをガマンした分だけ勇者が強くなり、「誘惑の塔」を上っていく iOS ゲーム。戦闘は自動（オートバトル）。
つもり貯金（使ったつもりで使わなかったお金）を記録すると、その額に応じてレベルが上がる。
試作版（ブラウザ）は `tsumori/prototype.html`。

---

## 1. 方針

- **勝ち負けは強さで決まる。強さはガマンで決まる。** 操作の腕前はいらない。工夫できるのは技の選び方だけで、効き目はレベル1つ分くらいに抑える
- **ゲームは毎日1〜2分。** 記録のついでに1戦して終わる重さにする
- **記録は1タップ。** 開いて、ガマンした物を押して、閉じる。これが5秒で終わることを最優先にする
- **嘘をつく理由を減らす。** 一度に大金を入れても、すぐには強くならない（1日の反映上限）。続けた日数で強くなる要素（守り）を用意する
- **お金を使わせない。** ガチャ、スタミナ、強化アイテムの課金はしない。「お金を使わないほど強い」と矛盾するため
- **合計額は本当の金額で見せる。** 強さとは別に、いくら貯まったかを常に円で表示する
- サーバーは使わない。記録は端末の中だけ（iCloud バックアップは MVP 後）

## 2. 用語

| 用語 | 意味 |
|---|---|
| ガマン | 買うのをやめた物の記録。品名と金額を持つ |
| 累計 | 取り消していないガマンの合計額。画面に円で出す |
| 反映済み | 累計のうち、レベルに反映された額 |
| 繰り越し | 累計のうち、まだレベルに反映されていない額（＝累計 − 反映済み） |
| 1日 | 午前4時で区切る（深夜0時〜4時の記録は前の日に入る） |
| 連続日数 | ガマンを1件以上記録した日が何日続いているか |
| おやすみ券 | 記録しなかった日に自動で使われ、連続日数を守る券 |
| 勇者 | プレイヤーの分身。レベルで攻撃力と HP が決まる |

## 3. ガマンの記録

### 3.1 プリセット（初期値）

| 品名 | 金額 |
|---|---|
| コンビニコーヒー | ¥150 |
| ペットボトル飲料 | ¥160 |
| コンビニおやつ | ¥200 |
| カフェのドリンク | ¥550 |
| ランチの外食 | ¥1,000 |
| タクシー | ¥1,500 |
| 飲み会の2次会 | ¥3,000 |
| トレカ 1パック | ¥180 |
| トレカ 1BOX | ¥5,500 |
| ネットのついで買い | ¥2,000 |

- プリセットはユーザーが追加・編集・削除・並べ替えできる。最大24個
- プリセット以外に「金額を入力して記録」（品名は任意、空なら「その他」）
- 金額は1件 ¥10〜¥100,000、1円単位。1日に記録できるのは30件まで

### 3.2 取り消し（やっぱり買った）

- 履歴の各行に「やっぱり買った」ボタン。2回押しで確定する（誤タップ防止）
- 取り消したガマンは、記録した日から無かったものとして計算し直す（4.1 の計算は全履歴から毎回出し直す純粋な計算なので、それで整合が取れる）
- その結果レベルが下がることがある。下がったときはそのまま表示し、責める演出はしない
- 取り消しの取り消しは無し（もう一度記録してもらう）

## 4. 強さの計算

すべて記録の一覧と「今日の日付」だけから決まる純粋な計算にする（`TsumoriCore` に置き、単体テストで固定する）。

### 4.1 反映（1日 ¥3,000 まで）

最初の記録日から今日まで、1日ずつ次を繰り返す。

```
使える額 = 前日までの繰り越し + その日の記録額
その日の反映 = min(3,000, 使える額)
反映済み += その日の反映
繰り越し = 使える額 − その日の反映
```

- 今日の分もすぐ反映する（記録した瞬間に強くなる）
- 例：BOX 1つ ¥5,500 をガマン → 今日 ¥3,000、明日 ¥2,500 が反映される
- ホームに「今日の反映 ¥x / ¥3,000」と「繰り越し ¥y（明日以降に反映）」を出す

### 4.2 レベル

レベル L に必要な反映済み額：

```
必要額(L) = 30 × L² + 70 × L     （上限 Lv99 = ¥300,960）
```

Lv0→1 は ¥100、そこから1レベルごとに必要額が ¥60 ずつ増える（Lv L→L+1 は ¥(100 + 60L)）。

| Lv | 必要額（累計） | 次のLvまで |
|---|---|---|
| 1 | ¥100 | ¥160 |
| 5 | ¥1,100 | ¥400 |
| 10 | ¥3,700 | ¥700 |
| 20 | ¥13,400 | ¥1,300 |
| 30 | ¥29,100 | ¥1,900 |
| 50 | ¥78,500 | ¥3,100 |
| 70 | ¥151,900 | ¥4,300 |
| 99 | ¥300,960 | — |

前回案の `10 × log10(累計÷100)` は後半の伸びが遅すぎた（¥10万から次のレベルまで ¥500/日 ペースで52日）ため、この2次式に変えた。後半でも1レベルが ¥500/日 で約9日。

### 4.3 レベルで決まるもの（攻撃力と HP）

| 項目 | 式 |
|---|---|
| 攻撃力 | 10 × 1.04^L（1レベルで4%、10レベルで約1.5倍） |
| 最大HP | 100 × 1.04^L |

| Lv | 攻撃力 | 最大HP |
|---|---|---|
| 0 | 10 | 100 |
| 10 | 15 | 148 |
| 25 | 27 | 267 |
| 50 | 71 | 711 |
| 70 | 156 | 1,557 |
| 99 | 486 | 4,856 |

- 掛け算（指数）で伸ばす。足し算（例：1 + L÷20）だと、後半は10レベル差でも1割しか違わなくなり、ガマンしなくても勝てるようになってしまうため
- 表示は整数に丸める。計算は小数のまま行う

### 4.4 連続日数で決まるもの（守り）

```
受けるダメージの軽減 = min(連続日数, 30) × 0.5%    （30日で最大 15%）
```

- 連続30日で、レベル約2つ分の強さになる（5.4 の表）
- 「今日」まだ記録していなくても、連続日数は昨日までの値で表示する（今日の終わりまでは途切れない）

### 4.5 技（レベルで解放、1つだけ装備）

| 解放 | 技 | 効果 |
|---|---|---|
| Lv10 | 会心の一撃 | 会心（1.5倍ダメージ）の確率 15% → 30% |
| Lv25 | 節約の盾 | 受けるダメージ −4%（守りの軽減と掛け合わせ） |
| Lv45 | 倍返し | 自分の HP が半分以下のとき、攻撃 ×1.15 |
| Lv70 | 満額回収 | 与えたダメージの 10% だけ HP が回復 |

- 装備できるのは1つ。戦う前にいつでも付け替えられる
- どれも勝率をレベル半分〜1つ分上げる程度で、4つの強さはそろえてある（5.4 の表）。どれが得かは相手の HP や素早さで変わる、というほど複雑にはしない（MVP 後に敵の特徴を足すときに考える）
- 解放したときは「新しい技：◯◯」と大きく演出する

### 4.6 おやすみ券

- 毎週月曜（4時区切り）に1枚もらえる。持てるのは2枚まで。最初に記録した週にも1枚もらえる
- 記録しなかった日が過ぎたとき、連続日数が1以上で券があれば自動で1枚使い、連続日数を守る（その日は日数に数えない）
- 券がなければ連続日数は0に戻る

### 4.7 レベル1年分の目安

| 毎日のガマン | 1週間 | 1か月 | 3か月 | 半年 | 1年 |
|---|---|---|---|---|---|
| ¥300 | Lv7 | Lv16 | Lv28 | Lv41 | Lv59 |
| ¥500 | Lv9 | Lv21 | Lv37 | Lv53 | Lv76 |
| ¥1,000 | Lv14 | Lv30 | Lv53 | Lv76 | Lv99 |

## 5. ゲーム：誘惑の塔（オートバトル）

### 5.1 構成

- 全100階。1階ごとにボス1体と1対1で戦う。戦闘は自動で、プレイヤーは見るだけ
- **推奨レベル = 階 − 1**（1階は Lv0、100階は Lv99）。推奨レベルちょうどで勝率は約8割
- クリアすると次の階が開く。強ければ何階でも続けて上れる（後から始めた人やレベルが上がった人が、まとめて追いつける）
- **負けた階は、日付が変わるか、レベルが上がるまで再挑戦できない。** 同じ強さのまま何度もやり直して、運で勝つのを防ぐ。「ガマンして強くなってから来い」がこのゲームの答え
  - 技の付け替えでは再挑戦できるようにしない
- 1戦は10秒前後。2倍速と「結果まで飛ばす」ボタンを置く

### 5.2 ボスの名前（10階ごとに誘惑の種類が変わる）

| 階 | ボス |
|---|---|
| 1〜10 | コンビニの誘惑 |
| 11〜20 | 自販機の誘惑 |
| 21〜30 | カフェの誘惑 |
| 31〜40 | サブスクの誘惑 |
| 41〜50 | タイムセールの誘惑 |
| 51〜60 | 送料無料まであと少しの誘惑 |
| 61〜70 | 限定品の誘惑 |
| 71〜80 | 新作パックの誘惑 |
| 81〜90 | 推しグッズの誘惑 |
| 91〜100 | 衝動買いの化身 |

表示は「コンビニの誘惑 3」のように番号をつける（100階だけ「衝動買いの化身・真」）。

### 5.3 戦闘の決まり

推奨レベル R（＝階 − 1）のとき、ボスは次の強さ。

| 項目 | 式 |
|---|---|
| ボスの HP | 4.5 × 攻撃力(R) |
| ボスの攻撃 | 最大HP(R) ÷ 4.2 |

- 勇者が先に攻撃し、勇者とボスが交互に1回ずつ攻撃する
- ダメージ = 攻撃 × 乱数（0.75〜1.25）。勇者の攻撃は 15% で会心（1.5倍）
- 勇者が受けるダメージに、守りの軽減（4.4）と技（4.5）をかける
- どちらかの HP が0以下になったら終わり。30往復で決着しなければ負け（実際には起きない）
- 乱数は「階・日付・レベル」から作ったシード（mulberry32）で決める。同じ条件なら同じ戦いになる（単体テストで固定できる）
- 推奨レベルちょうどだと、勇者は5〜6回攻撃してボスを倒し、ボスの攻撃を4〜5回受ける。HP が数割残るか、ぎりぎり負けるか、という戦いになる

### 5.4 勝率の目安

試作の戦闘関数でそのまま計算した値（51階、各4,000戦、技なし）。どの階でもほぼ同じになる（強さを全部 1.04^L の掛け算で決めているため）。

| 連続日数 | 推奨より3低い | 2低い | 1低い | ちょうど | 1高い | 2高い |
|---|---|---|---|---|---|---|
| 0日 | 19% | 39% | 62% | 81% | 94% | 99% |
| 7日 | 27% | 50% | 73% | 89% | 97% | 99% |
| 14日 | 41% | 64% | 83% | 95% | 99% | 100% |
| 30日 | 66% | 82% | 93% | 99% | 100% | 100% |

技を付けたとき（連続0日）：

| 技 | 1低い | ちょうど |
|---|---|---|
| なし | 62% | 81% |
| 会心の一撃 | 73% | 87% |
| 節約の盾 | 74% | 91% |
| 倍返し | 71% | 87% |
| 満額回収 | 71% | 88% |

- つまり **勝ち負けはほぼレベルで決まり、連続日数で最大レベル2つ分、技でレベル半分〜1つ分だけ前に出られる**
- 負けても「あと1〜2レベル上げれば勝てる」が見える差にしてある。レベル1つは、序盤なら1日、Lv50 前後なら ¥500/日 で約1週間のガマン

### 5.5 戦う前の画面

- ボスの名前・HP・攻撃、自分の攻撃力・HP・守り・装備中の技を並べる
- **勝率の目安**を出す（その場で300戦シミュレーションした結果を10%刻みで丸める）
- 勝率が7割未満なら、その下に **「Lv◯（あと¥◯のガマン）なら 勝率◯%」** を出す。次にレベルが上がったときの勝率を同じ方法で計算する

### 5.6 戦闘画面

- 左に勇者、右にボス。それぞれ HP バー
- 攻撃のたびにダメージの数字を飛ばす。会心は大きく色を変える
- 下に戦いの記録を1行ずつ出す（「勇者の攻撃！ 72ダメージ」）
- 速さは 1往復 0.8秒（2倍速で 0.4秒）

### 5.7 結果画面

- 勝ち：「◯階 クリア！」→「次の階へ」。初クリアのときは塔の何階まで来たかを出す
- 負け：ボスの残り HP（％）と、**「推奨 Lv◯ まで、あと ¥◯ のガマン（最短◯日）」**。最短日数は 1日 ¥3,000 の上限と繰り越しから計算する。自分が推奨以上のときは「明日もう一度挑戦できます」
  - ここがゲームと貯金をつなぐ一番大事な画面。「ガマンを記録」ボタンを並べて置く
- 広告で再挑戦はさせない（強さはガマンで買うもの、という筋を通す）

## 6. 本当の貯金（MVP 後半に入れる）

- 毎週日曜の夜に「今週のつもり貯金 ¥◯ を本当の貯金に移した？」と聞く（通知＋ホームのカード）
- 「移した」を押した額を「確定額」として別に数える。確定額で自機の見た目（スキン）が手に入る（¥1万・¥3万・¥5万・¥10万・¥30万）
- 確定額は強さには影響しない。強さはあくまで記録で決まり、確定は「現実の貯金」を後押しするご褒美

## 7. 通知

- 1日1回まで。時刻はユーザーが選ぶ（初期値 21:00）
- その日まだ記録していなければ「今日ガマンしたもの、ありますか？」
- 連続3日以上で、券がなく、まだ記録していない日は「連続◯日が今夜で途切れます」に変える
- 記録済みの日は送らない
- 初回起動ではなく、最初のガマンを記録した直後に通知の許可を求める（許可される率が高い）

## 8. 画面

| 画面 | 内容 |
|---|---|
| ホーム | 累計（円）、Lv と次のLvまでの残り額、今日の反映 / 繰り越し、連続日数・券、攻撃力・HP・守り・技、**プリセットのボタン群（ここで1タップ記録）**、金額入力、今日の記録 |
| 履歴 | 日ごとの一覧、取り消し |
| 誘惑の塔 | 階の一覧（推奨Lv・勝率の目安・クリア済み・再挑戦できる日） |
| 戦う前 | 5.5 の内容（勝率の目安、技の付け替え） |
| 戦闘 | 5.6 の内容 |
| 結果 | 5.7 の内容 |
| 設定 | 通知時刻、プリセット編集、データの書き出し（CSV） |

記録したときは、レベルが上がれば「Lv12 → 13」と攻撃力の増え方をトーストで出す。上がらなければ「次のLvまで あと¥◯」を出す。

## 9. データ（端末内、SwiftData）

```
Entry
  id: UUID
  createdAt: Date
  day: Int                 // 4時区切りのローカル日付を通し番号にしたもの
  presetId: UUID?
  name: String             // 最大20文字
  amount: Int              // 10〜100,000
  canceledAt: Date?

Preset
  id: UUID
  name: String
  amount: Int
  order: Int

Progress
  highestCleared: Int      // 0〜100
  equippedSkill: String?   // "crit" | "shield" | "revenge" | "drain"
  lastLoss: { floor: Int, day: Int, level: Int }?   // 再挑戦の制限に使う

Settings
  notifyHour: Int, notifyMinute: Int
```

- 反映済み・繰り越し・レベル・連続日数・券は保存しない。毎回 Entry から計算する（4章）
- 時計を戻すズルは対策しない（一人用なので損するのは本人だけ）。ただし未来の日付の記録は作れないようにする

## 10. 収益化

| 種類 | 内容 |

## 12. MVP の範囲

含める：
- 記録（プリセット・金額入力・取り消し）、反映・レベル・連続日数・おやすみ券
- 誘惑の塔 100 階（オートバトル）、技4つ、勝率の目安、結果画面の「あと¥◯」
- 毎日の通知
- バナー広告、広告削除
- 日本語のみ（英語は MVP 後）

MVP 後：
- 本当の貯金（6章）とスキン
- ホーム画面ウィジェット（累計と Lv）
- iCloud バックアップ
- CardAlertHub 連携：値下がり通知を見送ったときに「このカードをガマン」を1タップで記録
- 英語対応（通貨はその国のものにし、上限やレベル式は通貨ごとに係数を持つ）

## 13. 試作で確かめること

- 最初の3日で「強くなった」と感じるか（¥500/日 で 3日目に Lv6）
- 勝率の目安と「あと¥◯なら勝率◯%」を見て、ガマンしたくなるか
- 負けた階に今日はもう挑めない、という決まりが不満にならないか
- 1戦10秒、2倍速、結果まで飛ばす、の長さがちょうどいいか
- 1日 ¥3,000 の上限が、高額のガマンをした人に不満を与えないか

試作には「次の日へ」「7日進める」などの日付を進めるボタンがある（本番には入れない）。
